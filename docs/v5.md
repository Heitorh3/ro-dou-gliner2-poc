# V5

Textos de até 6.000 caracteres seguem por uma única inferência. Textos maiores
são divididos em chunks sobrepostos. A saída registra `text_chars`,
`chunk_count`, tamanho do chunk e overlap para facilitar o benchmark.

A deduplicação é deliberadamente conservadora nesta POC e deve ser validada
contra o formato real de saída do GLiNER2 antes da integração definitiva.
